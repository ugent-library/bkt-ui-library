Patterns

Activity rows

The lightweight row for dashboard side regions: an icon, a relative time, and one sentence naming who did what, ending in the work's title as the link. Recent activity and Added for you both use it.

Row grammar

Rows sit in an ol.list-unstyled whose aria-label says what it lists. The icon says who acted — if-message-ai for the Biblio assistant, if-user for a person, if-service for the Biblio team — and the sentence names the actor in bold. The title link opens the work's own view; the row carries no status badges.

Direct-added rows

Added for you rows follow the same grammar with one addition: a work whose state still needs completion carries a second line with the soft completeness hint and a quiet Complete link into the work's edit route — the strong completion action lives under Incomplete work. Work state, not source, decides: a reviewed work stays an informational row whoever added it. The quiet Not yours? helpdesk route lives on the work's own view and on the completion form, never on the row.
