Responsive state

The app sidebar starts expanded at xl and wider, and slim below xl. Crossing that breakpoint updates the state; the toggle remains available in both states.

This default keeps the work area primary in the narrow split-screen setup used by reviewers. The decision is recorded in docs/decisions/DD-002-narrow-backoffice-work-pane.md.

Layout integration

Place the canonical templates/partials/main-sidebar.html directly in the app shell. The shell owns its grid area, width, sticky position, and scrolling. See docs/UI-LAYER.md for the shell contract and docs/JAVASCRIPT.md for the toggle behavior.

Accessibility

Set aria-current="page" and .active on the current link. Keep the visible label inside .bt-sidebar__label; do not replace it with an aria-label.

Repeat each label in its tooltip. Tooltips are enabled only in slim mode, when the visible labels are hidden.
