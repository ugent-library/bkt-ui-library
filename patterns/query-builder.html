Patterns

Query builder

Advanced search opens over the results on public works. Every condition must match, and each keeps its field, operator and value visible.

The dialog

Opening adds &advanced=1 to the address and closing removes it, so Reload and Back restore the dialog. Closing returns focus to the control that opened the dialog, or to Advanced search when the page loaded with it open. Why a dialog: docs/decisions/DD-001-advanced-search-dialog.md.

The exit

Complete conditions update the address at once, so Show results, Escape and Close keep every condition. A live count announces each change through aria-live.

States

V1

  • builder-empty — a first visit.
  • builder-one-condition — opened with one filter, which becomes a row.
  • builder-fields — every V1 field.
  • builder-query-language — opened on a link the builder cannot edit.
  • no-results — no matches after Show results.

Explorations

  • explore-spelling — a live count and spelling feedback on one condition.
  • explore-or-groups — one-level OR groups.
  • explore-more-fields — public fields beyond V1.
