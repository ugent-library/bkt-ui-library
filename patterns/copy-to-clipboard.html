Copy to clipboard

Copy buttons with or without a visible label. One behaviour reads the displayed value, confirms the copy and restores the original button.

Contract

Put data-clipboard on the button and a <code> next to it in the same parent. The script copies that visible text, so there is no second value to fall out of sync. Button and <code> may sit in either order. For a dynamic source such as the active citation tab, add data-clipboard-target="<css selector>"; the selector is resolved when the button is clicked.

On success the copy icon becomes a check. A button with .btn-text temporarily reads “Copied”; an icon-only button temporarily uses “Copied to clipboard” as its accessible name. Primary and outlined copy actions also turn green for two seconds.

No inline onclick: the behaviour is the shared script, not markup. Button variants are documented on Buttons.

Icon with label

Wrap the visible action text in .btn-text. The button may resize naturally when that text changes to the success label.

Use aria-label for the action's accessible name. The visible icon changes without introducing text into the button.
