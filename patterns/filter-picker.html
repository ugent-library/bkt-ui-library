Filter picker & editor

Add high-cardinality filters without crowding the sidebar. The picker chooses a dimension, the editor sets its value, and chips show the applied state.

The complete pattern

A bt-toolbar holds the active chips, Add filter picker, and Clear all filters action.

Filter bar with two applied filters

Interaction

  1. Open Add filter and choose a dimension.
  2. Set one or more values in the editor, then apply them.
  3. Use the chip label to reopen and edit the filter.
  4. Use the chip's × to remove one filter, or Clear all filters to remove every filter.

The editor opens below its trigger and overlays the result list. On small screens, it flows inside the single Filters tray.

Consistent state and actions

  • Every editor keeps Apply, Cancel, and Remove filter in the same positions.
  • Multiple selections use the first value plus a count, such as “Climate change +2”.
  • The chip label edits the filter; its × removes it.
  • While an editor is open, its picker item and both chip halves use the active state.

The value of data-filter-bar prefixes every required host id. The complete markup contract lives under filter-bar.js in docs/JAVASCRIPT.md; editor and chip markup lives in templates/partials/filter-editor-templates.html.
