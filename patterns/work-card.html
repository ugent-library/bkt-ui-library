Work card

The primary unit for displaying research output in list and search contexts. Three variants: backoffice curator, backoffice researcher, and public. The card uses Bootstrap's card component as a structural base, with surface tokens and a small set of custom classes for domain-specific content.

Card grammar — region by region

Every work card is the same five regions: __meta (a metadata row — access + type in the header, and departments / projects / VABB / provenance on the backoffice card), __actions, __title, __authors (of __author spans), and __pub (the reference line, composed per WORK-CARD-REFERENCE-STYLES). Structural wrappers stay Bootstrap (card-header, card-body).

The title element is surface- and outline-dependent: <h2> on public search results, <p> on backoffice lists, deeper heading levels where the page outline requires (project detail uses <h4> under year <h3>s). The __title class is purely visual — SCSS requires no specific tag.

Access CTA states (Download, Log in, Select file, embargo text) live at Work actions.

__meta — public: access badge + type item; backoffice: status badge + access as meta item

Open access Journal article
Restricted access Book chapter
Embargo until 01/05/2027 Doctoral thesis
Lecture Second text item

Only open access carries colour: text-bg-success + if-open-access. Restricted and embargo are neutral text-bg-secondary badges separated by icon — if-lock, if-time — because both are correct outcomes, not warnings.

No files, or all files private, means no access element at all — private leaves no public trace. The separator renders only between consecutive meta items of the same row, never after the last — a stacked sub-list (projects) draws none. Badges, links and plain spans sit in a row without being items: __meta-item is what asks for a separator. On the backoffice the badge slot belongs to deposit status + visibility icon, and access joins the meta items — see Roles & views below.

__actions — Cite and Add to list on every card (v1)

__author — icons outside the link, hidden text inside it

Karen De Pauw (UGent, ORCID 0000-0002-1234-5678), Jonas Maes (UGent), Manuel Esperon-Rodriguez et al.

Authors are prose: comma text nodes between __author spans, up to ten names then et al. Icons sit inside the span but outside the <a> — spacing comes from CSS, and the hover underline stays off the gap. The visually-hidden identifier text inside the link carries what the icons show.

Harvard author-date, card variant: the year opens the line (authors and title live above), container titles in <cite>, linked parts keep their search links, datasets carry the year only. Full per-type composition: docs/WORK-CARD-REFERENCE-STYLES.md.

One card across roles and views

One layout everywhere. What varies per context: the role (researcher or curator; proxy later), the capability (editing your own work, reviewing someone else's, or read-only), and the view — in a filterable overview the year, journal and project are clickable filters; in a plain list they are text. Statuses and visibility per docs/DOMAIN-VOCABULARY.md (Work status — two axes).

The missing-metadata warning is automated and role-specific: researchers see what they must supply (full text, DOI or WoS ID, title, abstract, authors, keywords, projects); curators see the bibliographic completeness list (journal, publisher, year, ISSN, volume, issue, pages).
