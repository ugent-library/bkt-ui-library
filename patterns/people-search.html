Click-to-select rich rows — single select in a form

Deposit and curate forms select one person. Selection closes the list, fills the confirmation slot, and keeps the role attached to that person. Clear restarts the search.

Checkable rich rows — multi-select in a panel

Filter and query panels use checkboxes for multi-select. Keep the same identifying metadata in each label so namesakes remain distinguishable before selection.
