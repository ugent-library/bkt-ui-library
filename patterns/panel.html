Panel

A titled popover with content and optional actions, used inside a dropdown or overlay.

Anatomy

bt-panel contains a title, one or more body blocks, and an optional actions footer. For search-first panels, place the search body above a scrollable checklist body.

In a dropdown

On result cards, the panel is a Bootstrap dropdown menu with data-bs-auto-close="outside". Load its body on first open and keep it open while someone selects lists. Search re-renders on input, not keyup, so the native clear control also refreshes the checklist.

Uses

Use panels for add-to-list pickers and filter editors. On small screens, filter editors flow inside the filters tray.
