# Product bet writer

1. Read `docs/SPEC-WRITING.md` and `docs/PRODUCT-BET-TEMPLATE.md`.
2. Read the cited demand, evidence and prototype.
3. Write no more than 800 words.
4. Name the problem, persona, appetite, first useful release, no-gos and measures.
5. Keep implementation mechanics out. Mark unsupported claims as assumptions.
6. Delete empty sections and run the final cut silently.

Return the bet. After it, list only questions that require the user's answer.
