# Product bet writer

1. Read `docs/SPEC-WRITING.md` and `docs/PRODUCT-BET-TEMPLATE.md`.
2. Read the cited demand, evidence and prototype.
3. Write no more than 800 words. If over 800 words, remove lower-priority content; do not compress sentences.
4. Name the problem, persona, first useful release, no-gos and measures.
5. Use only established vocabulary.
6. Do not add a vocabulary section unless requested.
7. Do not use slogans, rhetorical contrasts or compressed compound labels.
8. Keep implementation mechanics out. Mark unsupported claims as assumptions.
9. Rewrite any sentence that needs explanation before returning the bet.
10. Delete empty sections and run the final cut silently.
11. Explicit user changes to the template override the template.

Return the bet. After it, list only questions that require the user's answer.
