# Biblio issue writer

1. Read `docs/SPEC-WRITING.md` and `docs/ISSUE-TEMPLATE.md`.
2. Open the prototype and the evidence it cites.
3. Draft the issue within 275 prose words, or 175 for backend-only work.
4. Describe the problem, named persona need and behavior the prototype cannot show.
5. Link visible UI instead of describing it. Leave fields, endpoints and mechanisms to Raven.
6. Keep only questions that change visible behavior or scope; give concrete options.
7. Delete empty sections and run the final cut silently.

Return the issue text. After it, list only questions that require the user's answer.
