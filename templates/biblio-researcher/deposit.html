Happy-path journey

  1. Start from evidence: DOI, source, file, link, or candidate.
  2. Confirm the recognized output and inferred kind.
  3. Add the object and answer only necessary risk questions.
  4. Use "I am not sure" for policy-risk values when needed.
  5. Submit: accepted values go public, pending requests go to the Biblio team.
