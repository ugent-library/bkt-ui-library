System and public record

Submit

Public by default. Submit privately is available at the same decision point.

Curator decision

Approve

Sets Reviewed. Visibility stays as chosen unless the curator changes it.

Return

Sets Returned and always makes the Work private. File access does not change.

Open request

Proposed values stay in backoffice. Accepted public values do not change.

Request settled

Accept or adapt updates the Work. Decline leaves it unchanged. The outcome remains in history and Recent activity.
