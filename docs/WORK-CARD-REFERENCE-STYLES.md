# Work card reference styles

The reference line on a work card — the grey line under the title — is a **named style, configurable per deployment**. This doc specifies the two UGent defaults: the public line reads as a citation, the backoffice line reads as scannable metadata. Where style configuration lives is raven's to design; the prototype renders the defaults as static HTML and names them.

Current-state inventory (what the lines do today): `WORK-CARD-CURRENT-STATE.md`.

---

## Public style: Harvard author-date, card variant

### Anchor

The style anchor is **`harvard-cite-them-right.csl`** — "Cite Them Right 12th edition (author-date/Harvard)" from the official CSL repository (github.com/citation-style-language/styles), CC BY-SA 3.0. It is open, machine-readable, maintained, and lives in the same CSL ecosystem the public site already uses for its `?style=` citation feature and that raven lists among its render formats.

Every example below was generated by running that style file through citeproc (2026-07-30) and then applying the card deviations — none of the punctuation is asserted from memory. One locale note: the renders used the en-US base locale; the style's en-GB terms differ in one visible place, `edn` instead of `ed.` for edition. The spec uses the en-GB form.

### Deviations from the anchor — the "card variant"

The card is not a bibliography entry; four deliberate deviations, applied uniformly:

1. **Authors dropped** — they are the card's contributor line, directly above.
2. **Title dropped** — it is the card title. The line therefore starts with `(year)`.
3. **Access tail dropped** — Cite Them Right ends entries with "Available at: DOI/URL"; on the card, access is the download icon and the identifier links, not the reference line.
4. **Fields with no raven backing are omitted** rather than approximated (per-type notes below).

Everything else — order, punctuation, `pp.`, `In` for containers, `Place: Publisher` — follows the rendered anchor.

### Per-type lines

Keyed to raven's 23 work types (`raven/docs/metadata-work-types.md`). Fields are raven's (`raven/docs/metadata-work-fields.md`); `date` renders at the precision it carries (fuzzy date — a year-only date renders as just the year, day-month parts appear only where stored).

| Work type | Line composition | Example |
|---|---|---|
| `journal_article` | `(year) journal_title, volume(issue), pp. start–end.` — `article_number` in place of pages for e-only articles | `(2024) European Journal of Crime, Criminal Law and Criminal Justice, 32(1), pp. 58–79.` |
| `book` | `(year) edition edn. place_of_publication: publisher (series_title).` | `(2024) 2nd edn. Ghent: Academia Press.` |
| `edited_book` | as `book`; editors appear on the contributor line ("has editors, no authors") | `(2024) London: Routledge.` |
| `book_part` | `(year) in book_title. place_of_publication: publisher, pp. start–end.` — no host-book editors on the card (matches old biblio; detail-page concern) | `(2024) in Handbook of Urban Ecology. London: Routledge, pp. 100–120.` |
| `book_review` | as `journal_article` — per raven's design ("carries the same venue and position fields") | `(2025) Journal of Ecology Reviews, 12(2), pp. 301–303.` |
| `reference_entry` | `(year) container. place: publisher, pp. start–end.` — intended shape; **raven fields missing** ⚑ | `(2023) Encyclopedia of Plant Science. Amsterdam: Elsevier, pp. 455–460.` |
| `journal_issue` | `(year) journal_title, volume(issue).` — editors on the contributor line | `(2024) European Journal of Crime, Criminal Law and Criminal Justice, 32(1).` |
| `conference_paper` | `(year) proceedings_title. conference.name, conference.location, pp. start–end.` — no publisher (no raven field) | `(2024) Proceedings of the 12th IFToMM World Congress. IFToMM World Congress, Tokyo, pp. 1–8.` |
| `conference_abstract` | `(year) [proceedings_title.] conference.name, conference.location.` | `(2024) IFToMM World Congress, Tokyo.` |
| `conference_poster` | as `conference_abstract` | `(2024) IFToMM World Congress, Tokyo.` |
| `conference_presentation` | `(year) conference.name, conference.location.` | `(2024) IFToMM World Congress, Tokyo.` |
| `preprint` | `(year) publisher [Preprint].` — whether `publisher` holds the server name is raven's call ⚑ | `(2026) bioRxiv [Preprint].` |
| `working_paper` | `(year) place_of_publication: publisher (series_title).` | `(2025) Ghent: Ghent University Faculty of Economics.` |
| `report` | `(year) Report report_number. place_of_publication: publisher (series_title).` | `(2025) Report RPT-42. Brussels: Agentschap Natuur en Bos.` |
| `doctoral_thesis` | `(year) PhD thesis. awarding_institution.` — awarding institution, never the publisher field | `(2024) PhD thesis. Ghent University.` |
| `magazine_article` | `(year) magazine_title, day month, pp. start–end.` — pages shown (matches old biblio); **raven pages field missing** ⚑ | `(2025) Eos Wetenschap, 14 June, pp. 22–27.` |
| `newspaper_article` | as `magazine_article` ⚑ | `(2025) De Standaard, 2 March, p. 7.` |
| `online_post` | `(year) publisher, day month.` — publisher holds the issuing publication (Substack, group blog) per raven's field note | `(2025) Open Access Belgium, 1 September.` |
| `media_appearance` | `(year) venue, day month.` | `(2025) Universiteit van Vlaanderen, 5 November.` |
| `lecture` | `(year) venue, day month.` — location sits inside `venue` per its field definition | `(2025) UGent Data Stewards seminar, Ghent, 20 October.` |
| `dataset` | `(year)` — bare, matching the old public site; publisher (Zenodo) shows in the backoffice scan only | `(2026)` |
| `software` | as `dataset`; version field is raven's question ⚑ | `(2026)` |
| `other` | generic fallback (below) | `(2024)` |

### Generic fallback

Types without a specific rule — `other`, and any future type before it gets styled — render `(year)` plus whatever styled fields they carry, in the order of the table above. This is the successor of the current public site's single uniform rule: the fallback is the floor, per-type rules are the upgrade.

### Resolved flags (M, 2026-07-30)

Deliberate extensions of the anchor, decided:

- **E-only articles**: `article_number` renders where pages are absent.
- **Book reviews render like journal articles** — follows raven's design ("carries the same venue and position fields"). Note in the prototype when built.
- **Conference location on the line** — name + location, the anchor's name-only is extended.
- **Host-book editors stay off chapter cards** — matches old biblio on both surfaces; editors are a detail-page concern. Note in the prototype.
- **Where old biblio showed a field raven lacks, the card follows old biblio** and the prototype carries a note per case (below). Where old biblio showed nothing (public dataset line), the card stays bare.
- **Preprint server-in-`publisher`** is raven's concern, not the card's; the line assumes whatever raven decides the field means.
- **Genre words stay, everywhere** — "PhD thesis.", "Report RPT-42.", "[Preprint]" render even though the type badge names the type. The word explains the field that follows it (awarding institution, report number, unrefereed status), and the line survives out of context as a valid Harvard fragment. Year-only lines were considered and rejected.
- **Line parts stay linked** — year, container title and other searchable parts remain clickable search links, as on the old public site. The Harvard reading and the link affordance coexist.
- **Italics trial** — container and work titles inside the line render italic, following the anchor. Review in the prototype.
- **No classification badge on the public card** — A1/A2 codes are evaluation vocabulary; they ride on records as a UGent field and stay off the public surface.
- **Contributor line = old public rule, existing card marking** — up to 10 names then `et al.`; every name links; UGent contributors carry the `if-ghent-university` icon + visually-hidden "(UGent)" as already used in `patterns/work-card.html`; identifier icons keep the hover popover (`popover--sm popover--dark` pattern, `elements/popovers.html`) with the visually-hidden DOM fallback.

### ⚑ Remaining — raven gaps to raise

The prototype demonstrates the intended shape with placeholder data and a note; the fields don't exist in raven's registry yet:

- `reference_entry`: no container title (the encyclopedia), no publisher, no pages — only universal fields. Old biblio showed all three (as `misc`); the card keeps showing them.
- `magazine_article` / `newspaper_article`: no pages field. Old biblio showed pages; the card keeps them.
- `software`: no version field.
- Docs inconsistency: the migration map carries biblio dataset `Publisher` → raven `publisher`, but the imprint applies-to list omits `dataset`. The backoffice scan needs it.

## Backoffice style: UGent metadata scan

The backoffice line is deliberately **not a citation** — curators scan fields, readers cite. This is the current production format (`SummaryParts()`, see `WORK-CARD-CURRENT-STATE.md`), kept as a named style and rekeyed to raven fields.

Sequence, rendered as separated meta items, each part only when present:

```
year · container · publisher · volume · (issue) · start–end
```

- **year** — the year part of `date`.
- **container** — per type: `journal_abbreviations[0]`, falling back to `journal_title` (journal_article, book_review, journal_issue); `book_title` (book_part); `proceedings_title` (conference types); `magazine_title` / `newspaper_title` / `venue` for the public-engagement types. Abbreviation-first is the scan style's signature.
- **publisher** — where the type carries it.
- **volume, (issue), pages** — where the type carries them.

Type-agnostic by construction: any of the 23 types renders whatever of these it has. One style rule for the whole catalog, robust to new types.

Parked quirks — possibly kept, to be decided (see `notes/PLAN-work-card.md`): a lone first page renders as `58` (no dash); the abbreviation-to-full-title fallback; raw unformatted embargo dates elsewhere on the card.
